# Calculator App

A simple web-based calculator built with HTML, CSS, and JavaScript.

## Features

- Basic arithmetic operations: addition, subtraction, multiplication, and division
- Live result display as you build the expression
- Clear button to reset the calculator
- Hover effects on buttons

## Technologies Used

- HTML5
- CSS3
- JavaScript (vanilla, no frameworks or libraries)

## Getting Started

1. Clone the repository:
````bash
   git clone https://github.com/shreyanshpranjalsingh/Calculator-app.git
````
2. Open the project folder:
````bash
   cd Calculator-app
````
3. Open `index.html` in any web browser.

## Project Structure

````
Calculator-app/
├── index.html    # Page structure
├── styles.css    # Styling
└── script.js     # Calculator logic
````

## How to Use

1. Click the number and operator buttons to build an expression.
2. The result appears live in the "Answer" box.
3. Click **Clear** to start over.
